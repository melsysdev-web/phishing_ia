ENGLISH:

AI Phishing Detector - Your intelligent companion for web safety.

Analyze URLs and webpage content in real-time to detect phishing, malware, and misinformation.

KEY FEATURES:

URL Analysis:
- Multi-Signal Detection: AI (Random Forest + RoBERTa) + VirusTotal + Google Safe Browsing + Fact Check APIs
- Instant Results: Get security verdicts in seconds
- Detailed Scoring: 0-100 risk score with confidence indicators
- Domain Analysis: Check age, HTTPS validity, and registration details
- History Tracking: Browse your analysis history

Content Analysis:
- Fake News Detection: Identify misinformation and fake content
- Confidence Scoring: See how confident the AI is about results
- Real-time Classification: RoBERTa-based content classifier

User Experience:
- Beautiful UI: Modern flat design with smooth animations
- Quick Popup: Fast analysis in the extension popup
- Detailed Sidebar: Full results with threat intelligence breakdown
- Configuration: Set custom backend URL and API keys
- No Installation Hassle: Works right out of the box

PRIVACY & SECURITY:

Your Privacy Matters:
- No data collection beyond analysis
- No tracking or analytics
- No account required
- All settings stored locally

Transparent Operation:
- 100% open-source code
- Community-reviewed
- Security-first design
- Fully auditable

HOW IT WORKS:

1. Install the extension (2 seconds)
2. Click the extension icon
3. Paste a URL or webpage text
4. Get instant threat assessment
5. Trust the multi-signal AI verdict

SUPPORTED THREATS:

- Phishing and credential theft
- Malware distribution
- Social engineering
- Unverified claims
- Suspicious domains
- Newly registered domains
- Missing HTTPS

PERFORMANCE:

- Instant results (cached)
- 60 FPS smooth animations
- Minimal memory footprint
- Smart caching (30-day warm cache)
- Works on desktop and tablet

CONFIGURATION:

After installation:
1. Right-click extension > Options
2. Set Backend URL (default: localhost:8000)
3. Add API Key if required
4. Toggle Production Mode for cloud backend
